Актуальный реестр отложенных задач, которые необходимо реализовать при изменении требований или масштабировании сервиса.

## Описание задач

### TD-001. ASP.NET Data Protection для HMAC

Секретный ключ HMAC хранится в `.env` / переменных окружения. При масштабировании на несколько инстансов или при необходимости ротации ключей — реализоватьASP.NET Data Protection API.

### TD-002. Авторизация вызывающих систем

Текущий API не проверяет авторизацию вызывающих систем. При необходимости разграничения доступа реализовать аутентификацию через API-ключи, OAuth2 или mTLS.

### TD-003. Batch-эндпоинт POST /persons/resolve/batch

При массовых запросах (миграция данных из внешней системы) реализовать batch-эндпоинт для пакетной идентификации.

### TD-004. Таблица users и системный пользователь

Для полноценного аудита кто выполняет операции реализовать таблицу `users` и привязку операций к системному пользователю.

### TD-005. Фоновый процесс удаления по расписанию

Реализовано в `src/Worker/`. Side-car процесс с cron-планировщиком, который периодически:
1. Обрабатывает отложенные отзывы с наступившей датой (`ProcessDeferredCessationsAsync`)
2. Выполняет реконсилизацию помеченных записей (`ReconcileAsync`)

### TD-006. Административный сайт

Визуальный интерфейс для:
- Просмотра списка физических лиц и их связей с внешними системами
- Управления отложенными отзывами
- Просмотра логов и аудита
- Мониторинга статистики (количество идентификаций, конфликты, дефекты)

### TD-007. Периодическая рассылка статистики по email

Автоматическая отправка отчётов по email с:
- Общим количеством идентификаций за период
- Количество конфликтов (PersonMatchStatus.Conflict)
- Количество дефектов по типам
- Количество отзывов (мгновенных и отложенных)
- Количество отменённых отложенных отзывов

### TD-008. Удаление ключа организационной единицы через административный сайт

Удаление ключа организационной единицы и всех связанных записей (связей с внешними ключами, отложенных отзывов) через интерфейс администрирования.
