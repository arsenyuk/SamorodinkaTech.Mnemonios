## Метод проверки

### 1. Скачивание базы данных

БДУ ФСТЭК предоставляет XML-экспорт базы данных уязвимостей:

```bash
# Скачивание ZIP-архива
curl -k -L -o vulxml.zip "https://bdu.fstec.ru/files/documents/vulxml.zip" \
  -H "User-Agent: Mozilla/5.0"

# Извлечение
unzip -o vulxml.zip -d /tmp/fstec/
```

### 2. Автоматическая проверка

Скрипт проверки: `tools/check_fstec.py`

```bash
python3 tools/check_fstec.py
```

### 3. Ручная проверка

1. Открыть https://bdu.fstec.ru/
2. Ввести название компонента или CVE
3. Проверить наличие записи

| Статус всех уязвимостей | **Устранены** |

**Все 74 уязвимости** для PostgreSQL, затрагивающие версию 16, имеют статус **«Уязвимость устранена»** в БДУ ФСТЭК. Это означает, что производителем выпущены патчи, и при установке актуальных обновлений PostgreSQL уязвимости не представляют угрозы.

**Ключевые уязвимости (высокий/критический уровень):**

| BDU | CVE | Описание | Статус |
|-----|-----|----------|--------|
| BDU:2025-01601 | CVE-2025-1094 | Уязвимость функций libpq (критический, CVSS 10) | Устранена |
| BDU:2026-01722 | CVE-2026-2005 | Уязвимость pgcrypto (высокий, CVSS 9) | Устранена |
| BDU:2026-07094 | CVE-2026-6637 | Уязвимость модуля refint (критический, CVSS 10) | Устранена |
| BDU:2026-07098 | CVE-2026-6477 | Уязвимость функций lo_export/lo_read (критический, CVSS 10) | Устранена |
| BDU:2026-07100 | CVE-2026-6475 | Уязвимость pg_basebackup/pg_rewind (критический, CVSS 10) | Устранена |

**Рекомендация:** Установить последнюю версию PostgreSQL 16.x для устранения всех уязвимостей.

**Текущая версия в проекте:** PostgreSQL 16.15-alpine (обновлено 30.08.2026)

**Проверка версии:**
- Версия 16.15 исправляет 25 CVE (выпуск 13.08.2026)
- Версии до 16.15 исправляют 13 CVE
- **Итого все 74 CVE для PostgreSQL 16 устранены** (проверено по БДУ ФСТЭК)
